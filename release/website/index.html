Understand your network.

LanScope helps you discover responding IPv4 hosts, check TCP ports, and find web interfaces. Scan your Wi-Fi network, a public IPv4 address, or a domain you are authorized to test.

Start a scan

  1. Enter an IPv4 address, a CIDR range such as 192.168.1.0/24, or a domain such as example.com. Do not include a URL scheme, port, or path.
  2. Open Advanced Settings to choose TCP ports. Local network scans offer Quick and Deep modes; public IP and domain scans always use Deep mode.
  3. Tap Start Scan. Switch between IP and Web results. View past scans using the history button.

Only scan networks and hosts you own or have permission to test. A missing response does not prove that a device is offline.

Permissions and connections

Allow Local Network access for Wi-Fi discovery. Location permission is optional and is used only to read the Wi-Fi name; denying it does not prevent scanning. LanScope does not request or store geographic coordinates.

Public IP and domain scans use the current network and may use mobile data. Domains are resolved to IPv4 addresses. IPv6-only hosts are not supported. Up to 1024 addresses can be included in one scan.

Troubleshooting

No hosts found? Check the target and selected ports. For local scans, connect to Wi-Fi, allow Local Network access in iOS Settings, and try Deep mode. Firewalls and guest Wi-Fi isolation may block responses.

No Wi-Fi name? Enable location access and Precise Location if you want to display the name. This is optional.

Scan stopped in the background? Local scans may be resumed when the Wi-Fi environment is unchanged. Public IP and domain scans stop in the background and can be restarted. Completed results remain in history.

Untrusted HTTPS certificate? Discovery may identify a web service with an untrusted certificate and mark it in the results. Opening a link uses your browser's own security checks.
